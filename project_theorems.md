# Foundations for Temporal Fair Allocation: Theorems & Roadmap

Before we define the actual online allocation algorithm in HeapLang, we need to construct a pure functional model of the algorithm in Rocq and prove its mathematical correctness.

## 1. Instance Constraints
The greedy algorithm requires a specific environment to guarantee TEF1. We will define these as predicates on our instances.

* **Definition: `single_item_arrival`**
  * **Semi-formal:** For every day $t$, the size of the arriving set of items is exactly 1. $|O_t| = 1$.
* **Definition: `binary_valuation`**
  * **Semi-formal:** For every agent $i$ and item $o$, $V_i(o) \in \{0, 1\}$.

## 2. Core Utility Lemmas (Bundle Math)
These lemmas prove the mathematical behavior of `additive_bundle_val` over `gset`. 

* **Lemma 1: Empty Bundle is Zero**
  * $V_i(\emptyset) = 0$.
* **Lemma 2: Additivity of Disjoint Bundles**
  * If $b_1 \cap b_2 = \emptyset$, then $V_i(b_1 \cup b_2) = V_i(b_1) + V_i(b_2)$.
* **Lemma 3: Single Item Addition**
  * If $x \notin b$, $V_i(b \cup \{x\}) = V_i(b) + V_i(x)$.
* **Lemma 4: Single Item Removal (Crucial for EF1)**
  * If $x \in b$, $V_i(b \setminus \{x\}) = V_i(b) - V_i(x)$.

## 3. Pure Algorithm & State Transitions
We must define a pure Rocq function `greedy_allocator` and prove it respects the physical rules of allocation.

* **Lemma 5: Greedy is Valid**
  * **Semi-formal:** The `greedy_allocator` produces a sequence of partitions that satisfy `is_disjoint` and `is_complete` at every step $t$.
* **Lemma 6: Utility Transition Step**
  * **Semi-formal:** When `greedy_allocator` assigns item $o$ to agent $k$ on day $t$:
    - $V_k(A_t[k]) = V_k(A_{t-1}[k]) + V_k(o)$
    - $\forall i \neq k, V_i(A_t[i]) = V_i(A_{t-1}[i])$

## 4. Pure Fairness Proof (The Core Math)
This is the hardest mathematical theorem of the project. We prove the pure algorithm maintains TEF1 inductively.

  Layer 1: Bundle Math (Already Complete ✅)
   - utility_empty, utility_singleton, utility_add, utility_remove.
   - Purpose: Bridges gset union/difference operations to nat addition/subtraction.

  Layer 2: State Transitions (Algorithmic Unfolding)
  Because build_cumulative is a recursive Fixpoint, we need lemmas that cleanly unfold its execution from day t to day S t so we don't have to repeatedly deal with the raw match statements in our fairness
  proofs.
   1. cumulative_bundle_zero: At $t=0$, build_cumulative returns ∅ for all agents.
   2. cumulative_bundle_step_winner: For the chosen recipient, their bundle at $S \ t$ is exactly their bundle at $t$ $\cup$ the newly arrived item.
   3. cumulative_bundle_step_loser: For any other agent, their bundle at $S \ t$ is exactly their bundle at $t$.

  Layer 3: Utility Transitions
  Combining Layer 1 and Layer 2. If we know how the sets change, how do the numbers change?
   4. utility_transition_winner: Using utility_add, prove that the winner's utility strictly increases by $V_i(o)$ (where $o$ is the single arriving item).
   5. utility_transition_loser: Losers' utilities remain identical.

  Layer 4: The Greedy Selection Guarantee
  We must prove that greedy_step_recipient actually does what it claims to do.
   6. winner_values_item_or_no_one_does: If any agent values the item $o > 0$, the chosen winner also values $o > 0$.
   7. winner_is_minimum: For any agent $j$ who values the item $o > 0$, the cumulative utility of the chosen winner is $\le$ the cumulative utility of $j$.

  Layer 5: EF1 Preservation (The Core Inductive Step)
  This is the heart of the mathematics. We assume the allocation is EF1 on day $t$, and we must prove it remains EF1 on day $S \ t$. We will use the binary_valuation ($V_i(o) \in \{0, 1\}$) hypothesis
  heavily here.
   8. greedy_preserves_EF1: 
      * Case A (Agent $i$ looks at the Winner $w$): If $i$ didn't envy $w$ yesterday, and $w$ got an item today, $i$ can just hypothetically remove that single item (using utility_remove) to maintain EF1.
      * Case B (Winner $w$ looks at Agent $j$): $w$'s utility increased, so they are even less likely to envy $j$.
      * Case C (Agent $i$ looks at Loser $j$): Neither changed, so EF1 is trivially maintained.

  Layer 6: The Ultimate Theorem
   9. greedy_is_TEF1: 
      * A direct induction t using cumulative_bundle_zero (base case: empty allocation is trivially EF1) and greedy_preserves_EF1 (inductive step).

* **Lemma 7: TEF1 Base Case**
  * **Semi-formal:** At $t=0$ (before any items arrive), the empty allocation is trivially TEF1.
* **Lemma 8: Greedy Step Preserves EF1**
  * **Semi-formal:** Assuming `binary_valuation` and `single_item_arrival`. If $A_{t-1}$ is EF1, and $A_t$ is generated by assigning the new item to the agent with the lowest utility among those who value it, then $A_t$ is EF1.
* **Theorem: `greedy_is_TEF1`**
  * **Semi-formal:** `single_item_arrival inst -> binary_valuation inst -> TEF1 inst (greedy_allocator inst)`.

## 5. Iris Verification (HeapLang)
Once the pure math is proven, the Iris proof is a straight refinement.

* **Definition: `is_alloc_state`**
  * A representation predicate tying physical pointers to the Rocq state.
* **Theorem: `greedy_alloc_prog_correct`**
  * **Semi-formal:** The Hoare triple proving `greedy_alloc_prog` computes `greedy_allocator`.
